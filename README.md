# Amazon Sales Analysis

## Project Overview

This project analyzes Amazon sales data to understand sales performance, customer behavior, product performance, revenue trends, payment methods, discounts, and order status.

## Dataset

The dataset contains 100,000 Amazon orders with information about:

- Order details
- Customers
- Products
- Categories
- Brands
- Quantity
- Pricing and discounts
- Tax and shipping cost
- Payment methods
- Order status
- Geographic information
- Sellers

## Excel Workbook Structure

The Excel workbook contains three sheets:

1. **Original Data** – Raw Amazon sales data
2. **Clean & Analysis** – Data cleaning, calculations, and PivotTable analysis
3. **Dashboard** – Final Amazon Sales Dashboard

## Key Metrics

- Total Orders: 100,000
- Total Amount: 91,825,647.92
- Total Units Sold: 300,140
- Average Order Value (AOV): 918.26
- Cancellation Rate: 3.03%

## Analysis Performed

- Monthly revenue analysis
- Category-wise revenue and order analysis
- Product-wise revenue analysis
- Customer-wise revenue analysis
- Brand-wise revenue contribution
- State and country-wise revenue analysis
- Payment method analysis
- Order status analysis
- Discount and Net Sales analysis
- AOV analysis

## Tools Used

- Microsoft Excel
- PivotTables
- Excel formulas

## Dashboard

The dashboard provides a visual overview of Amazon sales performance, revenue trends, category performance, customer contribution, payment methods, discounts, and order status.
